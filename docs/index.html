スニペット管理。

Tanzaku は Mac のスニペット管理アプリです。ショートカットで開くランチャーに思い出せる言葉を打てば、日本語の意味検索で目的のスニペットが見つかります。Claude Code などの AI エージェントからもスニペットを追加・整理できます。

Mac App Store で近日公開 できることを見る

macOS 14 以上。スニペットは Mac の中だけに保存されます。

API キーを環境変数から読むやつ
  • 環境変数からトークンを取得
    let token = ProcessInfo.processInfo.environment["API_TOKEN"]
    envkey
  • .envrc の雛形
    export API_TOKEN=... # direnv allow を忘れずに
    envrc
  • GitHub Actions の secrets 参照
    env: API_TOKEN: ${{ secrets.API_TOKEN }}
    ghsec
Return でコピー⌘ Return で貼り付け

覚えていなくても、すぐ出せる

スニペットが増えるほど、キーワードを覚えきれなくなります。Tanzaku は覚えている断片から探せるようにします。

ランチャーから意味検索

ショートカットで検索窓を開き、タイトル・本文・キーワードのあいまい検索と、日本語に対応した意味検索で探します。検索は Mac の中で行われます。

コピーか、そのまま貼り付け

選んだスニペットはクリップボードへコピーします。アクセシビリティの許可を与えれば、前面のアプリへそのまま貼り付けます。

AI エージェントから整理

MCP サーバーを内蔵し、Claude Code などからスニペットの検索・追加・更新ができます。削除は Touch ID で確認するので、誤って消されません。

AI エージェントに任せても、
消すかどうかはあなたが決める

Tanzaku の MCP サーバーは同じ Mac からの接続だけを受け付け、Tanzaku が発行するトークンを持つクライアントだけが使えます。AI エージェントがスニペットを削除しようとすると、Touch ID の確認が出ます。

claude mcp add --transport http tanzaku http://127.0.0.1:<port>/mcp

接続するコマンドとトークンは Tanzaku の設定画面に表示されます。
