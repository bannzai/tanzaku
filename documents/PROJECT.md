# tanzaku の要件

スニペット (定型文・コマンド・プロンプト) を保存し、Mac では入力中のどのアプリからでも呼び出せ、AI エージェントからも MCP で安全に扱えるアプリ。iOS からも同じスニペットを使える。

- なぜ作るか・何で成否を判定するか・決定の経緯: `documents/DIRECTION.md` (仮説・判定基準・必要な機能の一覧・決めたこと)
- 保存の形: `documents/data-model.md`
- 画面: macOS は `documents/design/`。iOS は `documents/DIRECTION.md`「デザインの方向」

ここには、`documents/DIRECTION.md`「必要な機能」の各項目を実装する時に満たす振る舞いを書く。

## 構成

| 成果物 | 配布 | 対応 OS |
| --- | --- | --- |
| Mac アプリ | Developer ID で署名・公証し、GitHub Releases で配布。更新は Sparkle | macOS 14 以上 |
| iOS アプリ (本体・共有シート・キーボード・App Intents) | App Store | iOS 17 以上 |
| `TanzakuKit` (ローカル Swift Package) | 上の全ターゲットが使う | 同上 |

## スニペット

- 必須は本文だけ。タイトル・キーワード・言語・色・フォルダ (0〜1 個)・タグ (0 個以上) は任意
- タイトルが無ければ本文の 1 行目を表示名にする
- キーワードはスニペットとスニペットグループで共通の名前空間で一意。重複する保存はエラーにして理由を表示する
- 本文は等幅で表示し、言語を選んだ時だけシンタックスハイライトを付ける
- 作成・更新した主体 (ユーザー / MCP クライアント名) を記録して表示する

## 検索 (Mac のランチャー・管理画面、iOS 本体・キーボード・App Intents で共通)

- キーワードの完全一致・前方一致、タイトル・本文のあいまい検索、オンデバイスの意味検索 (NLContextualEmbedding。日本語を含む) を組み合わせる
- 結果はキーワードが一致したものと意味検索で見つかったものを分けて返す
- 意味検索のベクトルは端末内で作り、端末の外へ送らない。スニペットの追加・更新で作り直す

## Mac

### 管理ウィンドウ

- 画面の構成は `documents/design/Manager.dc.html`。サイドバーのライブラリには「すべてのスニペット」とスニペットグループを置き、フォルダ・タグで絞り込む
- スニペットとスニペットグループの追加・編集・削除

### ランチャー

- グローバルショートカット (既定 ⌥Space、設定で変更可) で開く検索窓
- 選んだスニペットはクリップボードへコピーする。設定で許可した時だけ、前面のアプリへ直接貼り付ける
- 開いた直後 (検索語が空の時) は、最近使ったスニペットを使った日時の新しい順に最大 10 件出す。使ったことのあるスニペットが無い時は新規作成 (⌘N) の案内を出す
- 結果が無い時は、入力した言葉を下書きにした新規作成 (⌘N) へ進める

### スニペットグループとキーワード展開

- キーボード入力を監視し、スニペットグループのキーワードを打つと、入力中のアプリの入力欄のキャレットの位置 (アクセシビリティ API で取得) にメニューを出す。取れない時はマウスポインタの位置に出す
- ↑↓ と Enter で選ぶと、打ったキーワードを消して本文を入れる。Esc で閉じるとキーワードは残る
- 入力監視・イベント送信・アクセシビリティの許可が無い時は機能を止め、許可の手順を案内する
- 監視したキー入力はキーワードの判定だけに使い、保存も送信もしない

### MCP サーバー

- アプリに内蔵した localhost の Streamable HTTP サーバー。クライアントごとのトークンで認証する
- ツール: 検索・取得・追加・更新・削除
- 追加したスニペットには、追加したクライアントの名前のタグを付ける
- 削除はエージェントが書いた理由を受け取り、依頼元のクライアント名・理由・削除するスニペットの全文を表示して Touch ID で確認する (設定で切り替え、既定はオン)
- 設定に接続済みのクライアントの一覧を出し、クライアントごとに接続を取り消せる

### 設定・初回起動

- 設定: 一般 (ログイン時に起動・ランチャーのショートカット・直接貼り付け)、AI エージェント (MCP サーバーの状態・接続コマンド・アクセストークン・接続済みのクライアント・Touch ID の確認)、ライセンス
- 初回起動: ランチャーを開くキー・最初のスニペット・AI エージェントの接続の 3 ステップ (`documents/design/Onboarding*.dc.html`)。スニペットグループに要る許可 (入力監視・アクセシビリティ) は、スニペットグループを初めて作る時に案内する

## iOS

### 本体アプリ

- スニペットの一覧・検索・コピー・追加・編集・削除。フォルダ・タグ・スニペットグループで絞り込む
- iOS 標準のコンポーネントで組む (`documents/DIRECTION.md`「デザインの方向」)

### 共有シート

- 他のアプリで共有した文字列 (テキスト・URL) を本文にした新規スニペットの編集画面を開き、保存できる

### Spotlight・App Intents

- Spotlight の索引にスニペットのタイトルとキーワードを入れる (本文は入れない)。選ぶとアプリでそのスニペットを開く
- App Intents: スニペットを検索してクリップボードへコピーする。ショートカット・アクションボタンから使える

### カスタムキーボード

- 文字の入力キーと次のキーボードへの切り替えを持ち、フルアクセスが無くても文字入力ができる (Guideline 4.4.1)
- スニペットの一覧と検索から選ぶと `textDocumentProxy.insertText` で入れる。スニペットグループのキーワードを打つとキーボード内にグループのメニューを出す
- 入力した内容は保存も送信もしない

## 同期

- Mac と iOS のスニペット・フォルダ・タグ・スニペットグループを iCloud (CloudKit のプライベートデータベース) で同期する
- 意味検索のベクトルと MCP の接続先は同期しない

## ライセンス

- 無料はスニペット 20 件まで。購入で上限を外す
- Mac: Lemon Squeezy で購入したライセンスキーをアプリで有効化する (License API の activate / validate / deactivate)
- iOS: App Store の IAP (非消耗型)
- 価格と、一方で買ったライセンスをもう一方で有効にするかは関門 1 で決める

## 対象外

- バックエンド・アカウント作成・チーム共有
- 本文の変更履歴・ゴミ箱
- Firebase (Analytics・Crashlytics)
