# 方向性: tanzaku

## 仮説

AI エージェントを日常的に使う macOS の開発者は、スニペットが増えると略語を覚えきれずに探せなくなり、AI エージェントにスニペットを触らせたいが誤って消されるのは怖い。グローバルショートカットで開くランチャーの日本語の意味検索と、削除を Touch ID で確認する MCP サーバーを持つ買い切りの Mac アプリ (Developer ID で直接配布) にし、同じスニペットを iOS アプリからも使えるようにすれば、Dash の snippet の代わりに使われ、買い切りで払われる。

## 必要な機能

- [ ] スニペットの保存と管理画面 (本文・タイトル・キーワード・タグ・フォルダ・色の一覧・追加・編集・削除。必須は本文だけ)
- [ ] ランチャー: グローバルショートカットで開く検索窓。キーワード・タイトル・本文のあいまい検索と、オンデバイスの意味検索 (日本語を含む)。選んだスニペットはクリップボードへコピーし、ユーザーが許可した時だけ前面のアプリへ直接貼り付ける
- [ ] MCP サーバー: アプリに内蔵した localhost の Streamable HTTP サーバー (トークン認証)。スニペットの検索・取得・追加・更新・削除。削除は Touch ID の確認を挟む (設定で切り替え、既定はオン)
- [ ] スニペットグループ: キーワード (例: `;focus-app`) を打つと、入力中のアプリの入力欄のキャレットの位置にメニューを出し、グループに登録したスニペット (例: `deploy` / `release` / `run-test`) から 1 つを選ばせる。選ぶと打ったキーワードを消して本文を入れる。キャレットの位置が取れないアプリではマウスポインタの位置に出す。↑↓ と Enter で選び、Esc で閉じるとキーワードはそのまま残る
- [ ] iOS アプリ: 同じスニペットの一覧・検索 (あいまい検索とオンデバイスの意味検索)・コピー・追加・編集・削除。MCP サーバーとランチャーは Mac だけ
- [ ] iOS の共有シート (Share Extension): 他のアプリで選んだ文字列をスニペットとして保存する
- [ ] iOS の Spotlight・ショートカット (App Intents): iOS の検索にスニペットを出し、ショートカット・アクションボタンからスニペットを検索してコピーする
- [ ] iOS のカスタムキーボード: 任意のアプリの入力欄でスニペットを選んで入力する。スニペットグループのキーワードを打つと、キーボード内にグループのメニューを出す
- [ ] iCloud (CloudKit) 同期: Mac と iOS のスニペットを同期する。最初の版から入れる
- [ ] 買い切りライセンス: Mac は Lemon Squeezy で販売し、ライセンスキーをアプリで有効化する。iOS は App Store の IAP (Guideline 3.1.1)。無料はスニペット 20 件まで、購入で上限なし

## デザインの方向

macOS の画面デザインは `documents/design/` (Claude の Design キャンバスの書き出し。配置は `canvas.json`) で決定した

- macOS 標準のウィンドウ・サイドバー・グループ化した設定フォームに沿い、独自の UI 部品を増やさない。文字はシステムフォント、等幅はスニペット本文・コマンド・トークンだけに使う
- 短冊のモチーフは、スニペットごとの幅 4px の色の帯 (朱・藍・松葉・山吹・紫) と、藍の短冊 1 枚のアイコンにとどめる
- 使わないもの: クリーム色・オフホワイトの背景、見出しの一部だけの斜体、番号付きのラベル、等幅フォントのラベル、錠剤型のボタン、ガラス・ネオン・グラデーションの装飾
- 購入画面 (`documents/design/Purchase.dc.html`) の支払い先の文言と「購入を復元」のボタンは、Lemon Squeezy のライセンスキーの入力に書き換えた。キーの入力欄と有効化の流れは実装時に決める
- iOS 版は専用のデザインを作らず、macOS のデザイン (情報の並び・色の帯・文言・使わないもの) を参考に、iOS 標準のコンポーネント (`NavigationSplitView` / `NavigationStack`・`List`・`Form`・`.searchable`・`.swipeActions`・`ShareLink`・sheet) をなるべくそのまま組み合わせる
