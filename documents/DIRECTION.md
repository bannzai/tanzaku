# 方向性: tanzaku

## 仮説

AI エージェントを日常的に使う macOS の開発者は、スニペットが増えると略語を覚えきれずに探せなくなり、AI エージェントにスニペットを触らせたいが誤って消されるのは怖い。グローバルショートカットで開くランチャーの日本語の意味検索と、削除を Touch ID で確認する MCP サーバーを持つ買い切りの Mac アプリ (Developer ID で直接配布) にすれば、Dash の snippet の代わりに使われ、買い切りで払われる。

## 判定基準

| 指標 | 計測元 (skill / コマンド) | 継続のしきい値 | 打ち切り条件 | 転換の条件 |

| 14 日間のライセンスの売上 | 未定 (決済の仕組みの API。IAP・RevenueCat は使えなくなった) | 買い切り 3 本分以上 | 2 回連続で 0 かつダウンロードも 15 未満 | ダウンロード 50 以上で売上 0 が 2 回続いたら、無料枠・価格の転換 |

## 必要な機能

- [ ] スニペットの保存と管理画面 (本文・タイトル・キーワード・タグ・フォルダ・色の一覧・追加・編集・削除。必須は本文だけ)
- [ ] ランチャー: グローバルショートカットで開く検索窓。キーワード・タイトル・本文のあいまい検索と、オンデバイスの意味検索 (日本語を含む)。選んだスニペットはクリップボードへコピーし、ユーザーが許可した時だけ前面のアプリへ直接貼り付ける
- [ ] MCP サーバー: アプリに内蔵した localhost の Streamable HTTP サーバー (トークン認証)。スニペットの検索・取得・追加・更新・削除。削除は Touch ID の確認を挟む (設定で切り替え、既定はオン)
- [ ] スニペットグループ: キーワード (例: `;focus-app`) を打つと、入力中のアプリの入力欄のキャレットの位置にメニューを出し、グループに登録したスニペット (例: `deploy` / `release` / `run-test`) から 1 つを選ばせる。選ぶと打ったキーワードを消して本文を入れる。キャレットの位置が取れないアプリではマウスポインタの位置に出す。↑↓ と Enter で選び、Esc で閉じるとキーワードはそのまま残る
- [ ] 買い切りライセンス: 決済の仕組みは未定 (Developer ID での直接配布のため IAP は使えない)。無料はスニペット 20 件まで、購入で上限なし
