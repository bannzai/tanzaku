# スニペットの本文をログ・外部へ出さない

スニペットには API キー・トークン・社内の URL などの秘匿情報が入り得る。本文はユーザーのデータとして扱い、アプリの外へ出る経路を増やさない。

- スニペットの本文を `print` / `Logger` / クラッシュレポート / Analytics のイベントに入れない。ログに要る時は ID・文字数・ハッシュなど本文を復元できない値にする
- 本文を外部サービス (意味検索の API 等) へ送る経路は `documents/DIRECTION.md`「決めたこと」で決めた経路だけにし、送る内容・送り先はプライバシーポリシー (`docs/privacy-policy.md`) の記載と一致させる
- テスト・fixture・動作確認・issue・PR には明らかに偽の値 (例: `dummy-token-for-test`) を使い、実在の秘匿情報を貼らない
